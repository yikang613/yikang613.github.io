# yikang613.github.io

Source for Yikang Li's personal research and project website.

The site is intentionally static and dependency-free. Open `index.html` locally or serve the
repository root with any static HTTP server.

Validate the public content and internal links with:

```bash
python scripts/validate_site.py
```

Public URL after GitHub Pages deployment: <https://yikang613.github.io/>
